# Notebooks

Open [train_colab.ipynb](train_colab.ipynb) in Google Colab for GPU training
with the supplied YOLO splits. The notebook explains where to put the project
and dataset in Google Drive and saves the best checkpoint there.

Place exploratory Jupyter notebooks here. Install with `pip install -e '.[notebook]'`
and launch `jupyter lab` from the project root. Reuse the `guitar_chords` package
for preprocessing and models so experiments stay consistent with the CLI.
